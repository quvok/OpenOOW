# OpenOOW

Бесплатный открытый навигационный тренажёр для изучения судовождения и отработки решений на мостике.

## Текущий статус — v0.2

Первая интерактивная версия динамики собственного судна: телеграф двигателя 0–100%, разгон и замедление с ограничением ускорения, руль ±35°, скорость перекладки рулевого привода 2,3°/с, фактический угол руля, зависимость эффективности руля от квадрата скорости и запаздывание реакции рыскания, расчёт курса, ROT, скорости и пройденного пути, радарный вид сверху и фиксированный шаг симуляции 0,1 секунды.

Физика v0.2 намеренно упрощена: это учебная кинематическая модель с инерцией, а не валидированная гидродинамическая модель реального корпуса. Модель рулевого привода ограничивает скорость перекладки, а эффективность руля уменьшается на малой скорости. Это приближения, не результаты испытаний. Численные параметры — стартовые допущения; их нужно калибровать по данным конкретного судна.

## Запуск локально

    npm install
    npm run dev

Проверка и сборка:

    npm test
    npm run build

## Публикация

GitHub Actions запускает тесты, собирает Vite-приложение и публикует каталог dist в GitHub Pages после каждого push в main.

Адрес проекта: https://quvok.github.io/OpenOOW/

Если Pages ещё не активирован, откройте Settings → Pages и установите Build and deployment → Source: GitHub Actions.

## Следующие этапы

1. Калибровка ускорения и торможения по характеристикам судна.
2. Более точная модель поворота и бокового сноса.
3. Винт, двигатель, реверс и задержки рулевого привода.
4. Ветер, течение и волны.
5. Несколько судов, радар и ARPA.

OpenOOW не является сертифицированным тренажёром ПДНВ и не предназначен для использования при реальном судовождении.
