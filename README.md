# OpenOOW

Бесплатный открытый навигационный тренажёр для изучения судовождения и отработки решений на мостике.

## Статус

Начальная стадия разработки. Проект не является сертифицированным тренажёром ПДНВ и не заменяет официальную подготовку.

## Цели

- Модель движения собственного и целевых судов.
- Радиолокационная визуализация и ARPA.
- Учебные сценарии МППСС-72.
- Моделирование окружающей среды.
- 3D-мостик и навигационные приборы.
- Работа в браузере и отдельная сборка для Windows.

## Технологии

React, TypeScript, Vite, Canvas, Three.js, Tauri, Vitest.

## Запуск

```bash
npm install
npm run dev
```

## Принципы

- Бесплатное использование и открытый исходный код.
- Расчётное ядро независимо от интерфейса.
- Фиксированный шаг симуляции и воспроизводимые сценарии.
- Проверка навигационных расчётов автоматическими тестами.
- Все допущения физических моделей документируются.
