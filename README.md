# OpenOOW

Бесплатный открытый навигационный тренажёр для изучения судовождения и отработки решений на мостике.

## Текущий статус — v0.3.0

Реализован первый прототип динамики собственного судна:
- Телеграф двигателя 0–100%, разгон и замедление с ограничением ускорения.
- Руль ±35°, ограниченная скорость перекладки рулевого привода и отображение фактического угла.
- Упрощённая зависимость эффективности руля от скорости и запаздывание реакции рыскания.
- Расчёт курса, ROT, скорости и пройденного пути.
- 2D вид сверху для положения собственного судна.
- Независимый от React Simulation Engine с фиксированным шагом 0,1 секунды. UI передаёт команды и отображает состояние; расчётная логика находится в `src/core`.

Фиксированный цикл накапливает время между кадрами и выполняет целое число одинаковых шагов. Это устраняет зависимость численного интегрирования от частоты кадров. При одинаковом начальном состоянии, командах и временном шаге ядро должно воспроизводить одинаковый результат.

## Достоверность и ограничения

Текущая динамика — упрощённая кинематическая модель одного судна, а не валидированная гидродинамическая модель конкретного корпуса. Рулевой привод имеет ограниченную скорость перекладки, эффективность руля зависит от скорости, а реакция рыскания запаздывает. Эти зависимости являются приближениями. Численные параметры — стартовые допущения, не паспортные или испытательные данные; их необходимо калибровать по характеристикам конкретного судна.

Пока не реализованы полноценная модель двигателя и винта, задний ход, боковой снос, ветер, течение, волны, радар, ARPA, ECDIS, COLREG и 3D-мостик.

    npm install
    npm run dev

Проверка и сборка:

    npm test
    npm run build

## Публикация

GitHub Actions запускает тесты, собирает Vite-приложение и публикует каталог dist в GitHub Pages после каждого push в main.

Адрес проекта: https://quvok.github.io/OpenOOW/

Если Pages ещё не активирован, откройте Settings → Pages и установите Build and deployment → Source: GitHub Actions.
