# OpenOOW

Бесплатный открытый навигационный тренажёр для изучения судовождения и отработки решений на мостике.

## Текущий статус — v0.5.0

Добавлен первый учебный модуль расхождения с судами:
- Пять сценариев: встречное сближение, пересечение курсов (своё судно уступает), обгон, ограниченная видимость и несколько целей.
- Выбор и загрузка сценария с исходным курсом, скоростью собственного судна и условиями видимости.
- Схематичное отображение целей на PPI-подобном экране.
- Динамическое движение целей по заданным курсам и скоростям с фиксированным шагом 0,1 секунды.
- Обновление координат собственного судна и целей во время симуляции.
- Пересчёт текущих пеленгов, дистанций, TCPA и DCPA по относительному движению.
- Задача судоводителю, нормативная основа МППСС-72 и контрольные вопросы для разбора.

Также реализован первый прототип динамики собственного судна:
- Телеграф двигателя 0–100%, разгон и замедление с ограничением ускорения.
- Руль ±35°, ограниченная скорость перекладки рулевого привода и отображение фактического угла.
- Упрощённая зависимость эффективности руля от скорости и запаздывание реакции рыскания.
- Расчёт курса, ROT, скорости и пройденного пути.
- Независимый от React Simulation Engine с фиксированным шагом 0,1 секунды.

## Достоверность и ограничения

Динамика собственного судна — упрощённая кинематическая модель, а не валидированная гидродинамическая модель конкретного корпуса. Численные параметры — стартовые допущения.

Сценарии расхождения являются учебными постановками с постоянными курсами и скоростями целей. Координаты целей обновляются на каждом фиксированном шаге, а CPA/TCPA пересчитываются по текущим относительным векторам. Прогноз предполагает сохранение текущих курсов и скоростей; он не моделирует будущие манёвры целей, не является полноценным ARPA и не оценивает автоматически правильность действий судоводителя. Условия видимости и формулировки задач задают учебный контекст, но не заменяют полной оценки обстановки и всех применимых правил МППСС-72.

Пока не реализованы полноценная модель двигателя и винта, задний ход, боковой снос, ветер, течение, волны, динамические цели, ARPA-сопровождение и ECDIS.

## Запуск локально

    npm install
    npm run dev

Проверка и сборка:

    npm test
    npm run build

## Публикация

GitHub Actions запускает тесты, собирает Vite-приложение и публикует каталог dist в GitHub Pages после каждого push в main.

Адрес проекта: https://quvok.github.io/OpenOOW/

## Следующие этапы

1. Радарные настройки, EBL/VRM и отображение следов целей.
2. ARPA-сопровождение, сглаживание векторов и тревоги CPA/TCPA.
3. Оценка манёвров и проверка применимых правил МППСС-72.
4. Ветер, течение, волны и более точная модель маневренности.
