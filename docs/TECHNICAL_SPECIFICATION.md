# OpenOOW — Technical Specification

**Версия:** 1.0  
**Статус:** Утверждено для начала разработки  
**Тип:** Open Source maritime navigation simulator

## 1. Цель проекта

Разработать бесплатный навигационный тренажёр, моделирующий работу ходового мостика морского судна и позволяющий отрабатывать профессиональные навыки судоводителя.

Платформы:
- Современные браузеры на ПК.
- Мобильные устройства с адаптированным интерфейсом.
- Отдельное приложение Windows.

## 2. Основные функциональные модули

### 2.1. Bridge Simulator
- 3D-обстановка мостика и вид из окон.
- Управление рулём и главной машиной.
- Курс, скорость, обороты, перекладка руля.
- Компас, лаг, эхолот.
- Ветер, течение, видимость, волнение.

### 2.2. Radar
- Радиолокационные цели; настройка дальности и усиления.
- Sea Clutter и Rain Clutter.
- EBL и VRM; ручное измерение пеленга и дистанции.
- True Motion и Relative Motion.
- Head-Up, North-Up и Course-Up.

### 2.3. ARPA
- Захват и сопровождение целей.
- Векторы движения: True и Relative.
- CPA и TCPA.
- Lost Target и Target Swap.
- Trial Manoeuvre.
- Сигнализация опасного сближения.

### 2.4. COLREG-72
- Правила 5–10, 11–18 и 19–37.
- Огни и знаки; звуковые сигналы.
- Встречные, пересекающиеся и обгонные ситуации.
- Контекстная оценка действий судоводителя.

### 2.5. ECDIS
- Электронная карта; собственное судно и цели.
- Маршрутные точки и планирование маршрута.
- Контроль отклонения от маршрута.
- Опасные глубины и навигационные опасности.

### 2.6. Ship Handling
- Повороты и циркуляция; инерция и выбег; остановка.
- Влияние ветра и течения.
- Маневрирование в ограниченном пространстве.
- Швартовка, буксиры и постановка на якорь.

### 2.7. Emergency Training
- Man Overboard; Blackout; Steering Gear Failure.
- Main Engine Failure; Fire; Restricted Visibility.
- Collision Avoidance; Grounding Prevention.

### 2.8. Examination
- Сценарии с ограничением времени.
- Оценка действий, журнал событий и разбор ошибок.
- Система прогресса и настраиваемая сложность.

## 3. Технологический стек

- Frontend: React + TypeScript + Vite.
- 3D: Three.js.
- 2D Radar: Canvas.
- Simulation Core: TypeScript.
- Desktop: Tauri.
- Testing: Vitest + Playwright.
- Storage: IndexedDB.
- Hosting: GitHub Pages.
- Version Control: Git + GitHub.

## 4. Архитектура

Система модульная. Основные подсистемы:
- Simulation Engine.
- Ship Dynamics.
- Environment Model.
- Navigation Instruments.
- Radar Processing.
- ARPA Tracking.
- COLREG Assessment.
- Scenario Engine.
- Examination Engine.
- User Interface.

Simulation Engine не зависит от React или визуального интерфейса. Расчёт движения использует фиксированный временной шаг и воспроизводимые сценарии.

## 5. Требования к достоверности

- CPA/TCPA проверяются автоматическими тестами.
- Системы координат и единицы измерения документируются.
- Модели движения имеют явно обозначенные допущения.
- Ошибки и ограничения моделей не скрываются.
- COLREG-оценка учитывает контекст ситуации, а не только геометрию пересечения курсов.
- Сертификация ПДНВ не заявляется без соответствующего подтверждения.

## 7. Принципы разработки

- Бесплатное использование и открытый исходный код.
- Отсутствие обязательной регистрации.
- Отсутствие платных API и обязательных серверов.
- Основные функции работают офлайн.
- Автоматические тесты расчётных модулей.
- Резервные версии перед крупными изменениями.
- Документирование новых функций.

## 8. Ограничения

OpenOOW — учебный симулятор. Он не заменяет сертифицированные тренажёры, официальные навигационные карты, судовые приборы и профессиональную подготовку.
