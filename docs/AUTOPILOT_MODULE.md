# Автопилот OpenOOW

Версия: 0.21.0

## Функции

- Режим AUTO для удержания заданного истинного курса (Heading Control).
- Ввод уставки 0–359°T и корректировка ±1°/±10°.
- SYNC: принять текущий курс как новую уставку.
- Регулируемый предел команды руля 5–35°.
- Регулируемый порог сигнализации отклонения 2–20°.
- OFF COURSE индикация при превышении порога.
- При AUTO ручной орган задания руля блокируется; телеграф двигателя остаётся доступен.
- При отключении AUTO текущая команда руля сохраняется как начальная команда ручного управления.
- При загрузке нового сценария и сбросе автопилот отключается.

## Расчёт

`src/core/autopilot.ts` реализует чистую функцию `stepAutopilot`. Используется кратчайшая знаковая ошибка истинного курса и демпфирование по угловой скорости рыскания:

`rudder demand = clamp(1.2 × heading error − 22 × yaw rate, −rudder limit, +rudder limit)`

При скорости ниже 0,5 kn команда руля равна нулю. Физическая скорость перекладки по-прежнему ограничивается моделью рулевого привода в `stepShip`. Вызов происходит с фиксированным шагом 0,1 секунды.

## Ограничения

Это упрощённый учебный регулятор, не копия конкретной марки/модели судового автопилота. Он не моделирует Track Control по ECDIS, адаптивную настройку, compass/gyro errors, off-heading delay, rudder feedback fault, yaw damper tuning, weather adjustment, rate-of-turn mode, NFU, hand steering transfer transients или отказ рулевого привода. Не использовать как реальный навигационный прибор.
